# Mongoose HTTP Server V1.0

Released: 2026-11-24

Windows IPv4 static file server built from Mongoose. The tray menu provides
browser launch, settings, Windows service installation, and exit controls.
Directory listing is enabled by default.

## Run

Place `index.html` and the `files/` directory beside the executable. The tagged
source tree provides these under `web_root/`. Start the executable and open
`http://127.0.0.1:8000/`; the server uses the executable directory as its site
root.

The server uses plain HTTP without authentication or TLS and listens on IPv4
interfaces. Use it only on networks where that exposure is appropriate.
