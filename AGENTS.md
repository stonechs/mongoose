# Project instructions

- The project root is an independent Git repository.
- `upstream/` is the pristine Cesanta Mongoose clone. Do not edit it for local
  project work; copy only the needed source files into project-owned locations.
- Preserve existing user changes and review the root Git status before edits.
- Follow the upstream API declarations and examples in `upstream/mongoose.h`
  when integrating Mongoose.
- Record verified project status in `docs/project_status.md`.
